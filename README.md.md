# 근육 기원 통증 · 통합 웹앱

근거기반 근육 기원 통증 강의(1–8장, 종합)와 '통증 원인 찾기' 도구를 한 파일에 묶은 웹앱입니다.

- `index.html` 하나로 동작합니다. 인터넷 없이 파일을 바로 열어도 됩니다.
- GitHub Pages: Settings → Pages → Branch `main` / `/ (root)` → Save
  → `https://happyyang0226.github.io/muscle-pain-lecture/`

## 구성
- 상단 탭: 1장–8장, 종합, 통증 원인 찾기
- 각 장: 학습목표·인포그래픽·강의 슬라이드·퀴즈(확신도 표시·오답 심화)
- 통증 원인 찾기: 앞·뒤 몸 그림에 아픈 곳을 찍으면 후보 근육과 연관통 지도를 보여 줍니다(되돌리기 지원).
